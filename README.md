我用 Python 脚本把整套处理跑完了，成品在 process/ 目录下。用 Python 而不是 PixInsight，是因为脚本能全自动跑，每一步也都能看到结果、方便调整。

数据情况

- 相机 QHY183M（黑白），焦距 1197mm，约 0.41″/像素
- 7 个滤镜各 10 张，每张 5 秒，所以每个通道总共只有 50 秒
- 没有暗场、平场、偏置场，所以在叠加时补了几步：去热像素、去横纵条纹、去梯度

处理流程

1. stack.py：配准和叠加
   - 用星点最锐利的一张 L 作为基准帧。
   - LRGB 用三角形星点匹配来配准。
   - SHO 单张 5 秒的星点太少（只有 10–20 颗），三角匹配全部失败。改成做星点匹配，并用 RANSAC 精修。
   - 70 帧全部配准成功。整个过程中画面漂了大约 170 像素，旋转约 0.07°准可信。
   - 叠加用 3σ 剔除，并按星点 FWHM 加权，输出 master_L/R/G/B/S/H/O.fi
2. compose.py：合成
   - 先去条纹，再用二维多项式去梯度。
   - 用 FITS 头里的 WCS 坐标定位 M27，裁成 2000×2000。一开始按最亮区 83 的放大器辉光带偏了，所以改成按坐标定位。
   - 拉伸方式类似 PixInsight 的 STF 自动拉伸，然后做 LRGB 合成、降噪

局限和建议

- 窄带信号太弱。 SHO 每通道只有 50 秒，信噪比低；OIII 拉伸后比 Ha 强 带单张建议 120–300 秒，每通道至少 30 分钟。
- 星点偏软。 FWHM 大约 9 像素，约 3.7″，当晚视宁度一般。
- 建议补拍暗场和平场。 没有暗场，右侧放大器辉光和行条纹只能靠裁剪和算会好很多。
- 想在 PixInsight 里继续精修也可以。 直接打开 master_*.fits，它们是已着做 SPCC 色彩校准、BlurXTerminator 和 NoiseXTerminator。
