## 1. 一句话版本

| 校准帧 | 怎么拍 | 修正什么 | 运算 |
|---|---|---|---|
| **Bias 偏置场** | 盖上镜头盖，最短曝光 | 读出电路人为加的「底座」电平 + 固定的读出图案 | 减 |
| **Dark 暗场** | 盖上镜头盖，与亮场**同曝光、同温度、同增益** | 热噪声产生的暗电流、热像素、CMOS 放大器辉光（amp glow） | 减 |
| **Flat 平场** | 对准均匀光源（天空、光板），曝光到直方图约 1/3–1/2 | 暗角、灰尘圈（甜甜圈）、像素间灵敏度差异 | 除 |
| **Dark Flat 平场暗场** | 盖上镜头盖，与平场同曝光 | 平场本身的 bias + 暗电流 | 从平场里减 |

完整公式：

```
              Light − Dark_matched
Calibrated = ───────────────────────────────
             (Flat − DarkFlat) / mean(Flat − DarkFlat)
```

偏置场和暗场修正的是**加性**误差（不管有没有光都存在的信号），所以减；平场修正的是**乘性**误差（光被打了折扣），所以除。

## 2. 探测器信号模型：所有校准帧都来自这一个公式

CCD / CMOS 每个像素 (x, y) 读出的数字（ADU）可以写成：

```
Raw(x,y) = B(x,y) + D(x,y)·t + F(x,y)·S(x,y)·t + 噪声
            偏置       暗电流       平场响应 × 天空+目标
```

| 符号 | 物理来源 | 是否随曝光时间 t 变 | 是否随入射光变 |
|---|---|---|---|
| B | 读出放大器 / ADC 的偏置电平，电路图案 | 否 | 否 |
| D·t | 硅晶格热运动激发的电子（暗电流） | 线性增长 | 否 |
| F | 光学系统透过率 × 像素量子效率 | 否 | **乘在光上** |
| S | 真实的天空 + 天体信号 | — | — |

要求的是 S。解出来就是：

```
S·t = (Raw − B − D·t) / F
```

- `B` 由**偏置场**测量
- `B + D·t` 由**暗场**测量（暗场里已经包含了偏置）
- `F` 由**平场**测量（归一化到平均值 1）

每一种校准帧就是在「把光关掉」或「把光变均匀」的条件下，单独测出这个公式里的一项。
这个模型本身就是校准帧存在的全部理由。

### 为什么不能直接从亮场里估计？

- 暗电流和热像素在空间上是**固定图案**，和天空背景混在一起，单张亮场分不出来。
- 平场误差是**乘性**的：暗角让边缘的星和星云按比例变暗，用后期「去梯度」只能减掉背景的差异，减不掉星云本身被压暗的那部分（详见 [deepsky_postprocessing_pixinsight.md](deepsky_postprocessing_pixinsight.md) 第 2 节）。
- 灰尘圈是几十到几百像素的高频结构，多项式背景模型拟合不出来。

### 校准帧也有噪声

主暗场 / 主平场本身带噪声，减或除的时候噪声会**加进**结果。所以要拍多张合成「主帧」（master），N 张合成后噪声降到 1/√N。
一般建议每种 20–50 张以上；主暗场的噪声应明显低于单张亮场的读出噪声。

## 3. 偏置场 Bias

### 是什么

模数转换器（ADC）只能输出非负数。而读出噪声是围绕 0 上下波动的，如果不加处理，负的部分会被截成 0，平均值就偏了。
所以相机厂商在读出时**人为加了一个正的偏置电压**（offset / pedestal），让暗像素也落在几百到几千 ADU，而不是 0。

偏置场 = 曝光时间趋近 0 时读出的图像 = 这个底座 + 电路的固定图案（列条纹、读出放大器附近的渐变）。

### 从哪里来

偏置的概念来自电子学里的「零点」（zero level）。早期专业 CCD 系统在芯片旁读出额外的若干列「过扫描区」（overscan）——这些像素不对应任何感光区，只记录读出电路的电平，用来逐帧追踪偏置的漂移。
IRAF（见第 7 节）里偏置合成的命令就叫 `zerocombine`，直到今天专业流程仍把偏置叫 **zero frame**。

### 业余场景下的注意

- **偏置场在暗场缩放（dark scaling）时才是必需的**：如果暗场和亮场的曝光时间、温度完全一致，暗场已经包含了偏置，就不需要单独减偏置。
- 一些 CMOS 传感器（典型的是 2016 年前后流行的 Panasonic MN34230，用于 ZWO ASI1600 等）在极短曝光下偏置不稳定，**短曝光的偏置不能代表长曝光的底座**，这时社区普遍改用「平场暗场」代替偏置。

## 4. 暗场 Dark

### 是什么

即使完全没有光，硅里的电子也会因为热运动跃迁到导带，被像素收集。这就是**暗电流**，单位常写成 e⁻/像素/秒。

暗电流的三个特征决定了暗场怎么拍：

1. **随时间线性累积** → 暗场必须与亮场**同曝光时间**（或者用偏置 + 缩放）
2. **随温度指数增长**：经验上每升高约 6–7 °C 翻一倍 → 必须**同温度**，这就是制冷相机存在的理由
3. **每个像素不一样**：大部分像素暗电流很小，少数「热像素」（hot pixel）是平均值的几十倍 → 形成固定图案

CMOS 还有一项：**放大器辉光（amp glow）**——片上读出电路发热或发出的微弱红外光，在图像某个角落形成一片亮区，也随时间累积，暗场同样能减掉。

### 暗场减掉的不是噪声，而是「信号」

这是最常见的误解。暗场减掉的是暗电流的**平均图案**（期望值），不是暗电流的随机涨落（散粒噪声）。
暗电流的散粒噪声 √(D·t) 留在图像里，减不掉，只能靠低温让 D 变小。所以：

- 减暗场 → 去掉热像素、amp glow、不均匀的暗背景（固定图案）
- 制冷 → 降低暗电流本身，从而降低它的噪声

### 从哪里来

「暗电流」（dark current）这个词比 CCD 早几十年，来自**光电管和光电倍增管**（PMT）。
1910–1940 年代，Joel Stebbins、Albert Whitford、Gerald Kron 等人把光电管装到望远镜上做恒星测光。光电阴极在没有光照时也会发射热电子，形成一个本底电流，被称为 dark current。
那时的做法就已经是「关上快门测一次本底，从读数里减掉」——这正是暗场的祖先。光电倍增管也很早就被放进干冰里冷却来压低暗电流，和今天的制冷相机是同一个思路。

CCD 进入天文之后，暗电流从「一个数」变成了「一张图」（每个像素一个值），于是有了暗**场**（dark frame）。

## 5. 平场 Flat

### 是什么

同样亮度的光落在不同像素上，读数不一样。原因有三层，尺度从大到小：

| 来源 | 空间尺度 | 典型表现 |
|---|---|---|
| 暗角（vignetting） | 整幅 | 中心亮、四角暗，可差 10–50% |
| 灰尘 | 几十到几百像素 | 圆形暗圈「甜甜圈」（灰尘在焦前，投下的是离焦的光瞳影子，所以是环形） |
| 像素响应不一致（PRNU） | 单像素 | 每个像素量子效率差 1% 左右，形成细微的固定图案 |

这三者都是**乘性**的：它们按比例削弱进来的光。所以平场要**除**，而不是减。

平场的拍法就是让探测器看一个**均匀光源**：如果入射光完全平坦，拍到的图像里所有不平坦都来自光学系统和探测器本身——这就是 flat field 这个名字的含义。

### 为什么要归一化

平场图本身的绝对亮度没意义，只关心相对差异。除之前先把平场除以它的平均值（或中值），让它在 1 附近，这样校准后亮场的总体亮度不变。

### 平场的光源演化

| 方法 | 出现时间 | 说明 |
|---|---|---|
| 圆顶平场（dome flat） | CCD 早期（1970s 末–1980s） | 拍照圆顶内壁上被灯照亮的白色屏 |
| 晨昏平场（twilight flat） | 1980s | 日落后 / 日出前天空亮度均匀、足够亮 |
| 天空平场（sky flat / super flat） | 1980s–1990s | 把多张抖动（dither）拍摄的科学帧取中值，星星被剔除，剩下的就是真实天空照射下的响应 |
| T 恤平场（T-shirt flat） | 业余，2000 年代 | 镜头前蒙一层白 T 恤，对着黎明天空，起散射均匀化作用 |
| 电致发光板 / LED 光板（flat panel） | 业余，2000 年代末至今 | 可重复、随时可拍；后来出现带电动盖子的「平场盖」 |

圆顶灯的光谱和夜空不同，而像素响应与波长有关，所以专业上常用「圆顶平场修高频 + 天空平场修低频」组合，这一套在 1980 年代的 CCD 观测手册里已经成形。

### 平场为什么必须「不动光路」

平场测的是**当时那套光路**的响应。只要调了焦、转了相机、换了滤镜，灰尘影子的位置和暗角都会变。
所以：**每个滤镜单独拍平场，拍完亮场不要动光学系统**，最好当晚拍。

## 6. 平场暗场 Dark Flat 与其他变体

| 名字 | 是什么 | 为什么出现 |
|---|---|---|
| **Dark Flat / Flat Dark** | 与平场同曝光、同温度的暗场 | 平场里也有偏置和暗电流，要先减掉再归一化，否则除法就不对。CMOS 时代偏置不可靠后，用它代替偏置 |
| **Dark Library 暗场库** | 预先在多个温度、增益、曝光组合下拍好的暗场 | 制冷相机温度可控，暗场可以重复使用，不必每晚拍 |
| **Dark Scaling / Dark Optimization** | 用偏置把暗场的暗电流部分按 `t_light/t_dark` 缩放，或自动求一个最小化噪声的系数 | 暗场与亮场曝光时间不同、或温度略有差异时的补救；PixInsight 的 ImageCalibration 默认有优化选项 |
| **Bad Pixel Map / Cosmetic Correction** | 用热像素 / 冷像素位置表把坏点替换为邻域中值 | 暗场减不干净的残余热像素；没有暗场时的替代方案。见 `calibrate.py` 的 `--cosmetic` |
| **Dithering 抖动** | 每拍几张就把望远镜挪动几个像素 | 让固定图案在配准后落在不同位置，叠加时被离群值剔除掉。业余用它补偿暗场不完美，专业上本来就用来做天空平场 |

## 7. 历史：从照相底片到 CMOS

```
1839  银版照相         ── 天文照相起点
1880s 干版 + 长曝光     ── 深空天体照相（Draper 1880 猎户座星云，Common 1883）
1890  Hurter & Driffield 特性曲线（H&D curve）── 底片响应的标定
1910s–1950s 光电测光（光电管 → 光电倍增管）── "dark current" 一词，关快门测本底
1960s–70s 电视型探测器（Vidicon、SEC 管、像增强器）── 严重不均匀 → 必须做 flat field
1969  Boyle & Smith 在贝尔实验室发明 CCD（2009 诺贝尔物理学奖）
1976  第一批天文 CCD 图像（JPL 与亚利桑那大学，Mt. Lemmon 1.5 m 望远镜，拍天王星、土星、木星）
1979– 基特峰等天文台开始普及 CCD；bias / dark / flat 三步法定型
1981– IRAF 在 NOAO 开发，ccdproc / zerocombine / darkcombine / flatcombine
1983  HST 的 WF/PC 选用 CCD（1990 发射）
1989  SBIG ST-4 → 业余 CCD 时代开始（ST-4 先作为导星相机）
1990s 业余制冷 CCD（SBIG ST-6/7/8 等）；MaxIm DL、CCDSoft、Iris 等软件内置校准
2003–05 单反天文摄影兴起（Canon 10D/20D/20Da）；DSLR 无制冷，暗场温度难匹配
约 2006 DeepSkyStacker 免费发布，「lights / darks / flats / bias」四类帧成为业余标准术语
2003–04 PixInsight 首个版本；之后 BatchPreprocessing → WBPP（2019 年起大改）
2010s 中后 CMOS 制冷天文相机（ZWO、QHY 等，Sony IMX 系列）── amp glow、偏置不稳 → 平场暗场、暗场库
```

### 7.1 照相底片时代：没有暗场，但已经有「标定」

照相乳剂的工作原理是光化学反应，没有「热电子」累积的问题，所以**底片时代没有暗场这回事**。但有两个对应物：

- **灰雾（fog）**：显影过程中未曝光的银盐也会少量还原变黑，相当于一个均匀的本底。做底片测光时要量一块未曝光区域的密度扣除掉——这是偏置 / 本底扣除的雏形。
- **特性曲线**：1890 年 Ferdinand Hurter 和 Vero Charles Driffield 发表了底片密度 vs. 曝光量对数的关系（H&D 曲线）。底片是**非线性**的，天文学家在底片边缘印上一排已知亮度梯级的「标定斑」（sensitometer spots），用来把密度换算回光强。

底片时代的平场问题同样存在（暗角、乳剂不均匀），但因为底片非线性、每张都不同，只能靠目测或者把目标放在视场中心回避，很难系统修正。
CCD 的出现之所以革命性，一大原因就是它**线性**：信号与光子数成正比，于是上面第 2 节那个线性模型成立，减法和除法才有意义。

### 7.2 光电测光：dark current 的诞生

20 世纪初，Joel Stebbins 先用硒光电池、后用碱金属光电管做恒星光度测量；1930–40 年代 Whitford、Kron 等人改进放大和冷却；二战后 RCA 1P21 光电倍增管成为标准测光器件（Johnson 和 Morgan 1953 年的 UBV 系统就是用它定义的）。

这些器件都有一个问题：没有光的时候电流也不为零。这个电流叫 **dark current**，主要来自光电阴极的热电子发射。观测流程里固定有一步：**关上快门（或把星移出光阑）读一次本底，然后从星的读数里减掉**。同时把光电倍增管装进干冰盒里冷却，以压低暗电流。

CCD 继承了这个名字和这套思路，只是把一个数变成了一张图。

### 7.3 电视型探测器：「平场」成为必需

1960–70 年代，天文学家试过各种电子成像管：Vidicon、SEC Vidicon、像增强器 + 底片、早期的光子计数系统（如 1970 年代的 IPCS）。
这些器件的共同缺点是**响应极不均匀**——不同位置的灵敏度可以差几十个百分点，还会随时间漂移。
为了得到任何可用的测光结果，必须对一块均匀照明的光源拍一张图，然后逐像素相除。「flat field」作为数据处理步骤就是在这个阶段普及的。

### 7.4 CCD：三步法定型

1969 年 Willard Boyle 和 George Smith 在贝尔实验室发明了电荷耦合器件。最初是作为存储器设计的，很快发现它也是优秀的成像器件。
1976 年，JPL 的 James Janesick 和亚利桑那大学的 Bradford Smith 等人把一块 CCD 装到 Mt. Lemmon 的 61 英寸（约 1.5 m）望远镜上，拍到了天王星、土星和木星的图像，这是公认的第一批天文 CCD 图像。

CCD 的量子效率比底片高几十倍、线性、可数字化，但它有：读出偏置、暗电流、像素响应不均、坏列。天文学家很快在 1970 年代末到 1980 年代初把处理流程固定下来：

```
1. 读 overscan 区，逐行减偏置电平
2. 减主 zero 帧（偏置的二维结构）
3. 如有必要，减缩放后的主 dark 帧
4. 除以归一化的主 flat 帧
5. 修坏列 / 坏像素
```

这套流程被 1981 年开始在美国国家光学天文台（NOAO，基特峰）开发的 **IRAF** 写成了 `ccdproc` 任务，配套 `zerocombine`、`darkcombine`、`flatcombine` 三个合成命令。
Massey 的《A User's Guide to CCD Reductions with IRAF》（1990s）和 Howell 的《Handbook of CCD Astronomy》（2000）把它变成了天文学生的标准教材。
今天 Python 的 `astropy` 生态里的 `ccdproc` 包，名字就是直接继承 IRAF 的。

### 7.5 业余：从 SBIG 到 DeepSkyStacker 再到 PixInsight

1989 年 SBIG 推出 ST-4，起初作为自动导星器，很快被业余爱好者拿来拍图。1990 年代 SBIG、Starlight Xpress、Apogee 等推出了业余制冷 CCD，随机附带的软件已经内置 bias / dark / flat 校准，术语照搬专业。

2000 年代中期，佳能 EOS 10D、20D 以及专门为天文改装的 **20Da（2005）** 让单反成为主流入门设备。单反没有制冷，**暗场的温度很难与亮场匹配**，所以当时出现了大量关于「暗场到底要不要拍」「拍完亮场立刻拍暗场」的讨论，以及用抖动 + 离群值剔除来替代暗场的做法。

**DeepSkyStacker**（Luc Coiffier，约 2006 年起免费发布）把校准帧分成 Light / Dark / Flat / Offset(Bias) / Dark Flat 五个标签页，这套术语成了中文和英文业余圈的通用叫法。

**PixInsight**（Pleiades Astrophoto，Juan Conejero，2003–2004 年首个版本）的 ImageCalibration、ImageIntegration、以及后来的 BatchPreprocessing 脚本和 **WBPP**（Weighted Batch PreProcessing，2019 年后由 Roberto Sartori 等人大幅重写）把整套校准自动化了，包括暗场优化、按曝光 / 滤镜 / 温度自动匹配。

### 7.6 CMOS 时代的新问题

2010 年代中期起，基于 Sony IMX 系列和 Panasonic 传感器的制冷 CMOS 相机（ZWO ASI、QHY、Atik 等）逐渐取代 CCD。CMOS 带来了几个新现象，直接改变了校准习惯：

| 现象 | 影响 |
|---|---|
| 放大器辉光（amp glow） | 必须用**完全匹配**的暗场，不能用偏置 + 缩放 |
| 短曝光偏置不稳定（部分型号） | 改用**平场暗场**代替偏置 |
| 增益 / 偏置可调 | 暗场库必须按 gain + offset + 温度 + 曝光分别建立 |
| 读出噪声很低（1–2 e⁻） | 可以拍大量短曝光，暗电流相对贡献变小 |
| 新一代 Sony 背照式传感器暗电流极低 | 有人只用平场 + 平场暗场 + 抖动，省略暗场 |

## 8. 为什么专业天文台很少拍暗场，而业余必须拍

这是一个常让初学者困惑的反差。

**专业 CCD** 通常用液氮杜瓦冷却到 −100 °C 左右，暗电流低到每小时只有几个电子，远低于读出噪声和天空背景噪声。对于这类相机，偏置 + 平场就够了，暗场往往只是定期测一下确认没问题。专业流程的重点一直是 **zero + flat**。

**业余相机** 用半导体（帕尔贴）制冷，一般只能比环境低 30–40 °C，工作在 −10 到 −20 °C；单反完全不制冷，夏天传感器可以到 30 °C 以上。按「每 6–7 °C 翻倍」算，单反的暗电流比专业相机高出好几个数量级。热像素满屏、amp glow 明显，**不减暗场图像就不能用**。

所以暗场在业余圈的地位远比在专业圈高，这是设备条件决定的，不是专业天文台「偷懒」。

## 9. 名字的来历

| 名字 | 来历 |
|---|---|
| **Light frame 亮场** | 相对于 dark frame 而言的「有光的帧」，业余圈的说法；专业上叫 science frame / object frame |
| **Dark 暗场** | 继承光电测光时代的 dark current |
| **Bias 偏置场** | 电子学术语 bias（偏置电压）；专业上叫 zero frame，来自 IRAF `zerocombine` |
| **Offset** | 相机驱动里调偏置大小的参数名；DeepSkyStacker 用 Offset 指偏置场 |
| **Flat 平场** | 拍「平坦」光源，修正「平坦响应」；电视型探测器时代确立 |
| **Master** | 多张合成后的主帧，如 master dark、master flat |
| **Pedestal 底座** | 校准后加回的一个常数，避免减法产生负值被截断（PixInsight 的 Output pedestal） |

中文里「暗场 / 平场 / 偏置场」是对 dark / flat / bias frame 的直译，「亮场」是后来业余圈对应 dark 造的词。

## 10. 实践要点与常见误区

### 拍摄要点

1. **暗场**：同曝光、同温度、同增益 / 偏置、同 binning。盖紧镜头盖，相机遮光（单反要盖取景器）。
2. **平场**：每个滤镜、每次调焦 / 转相机后都要拍；曝光让直方图峰值在满阱的 1/3–1/2，避免进入非线性区；曝光不要太短（< 1 s 时某些机械快门会产生不均匀，CMOS 无此问题）。
3. **平场暗场**：与平场同曝光同温度。
4. **数量**：每种 20–50 张以上，越多主帧越干净。
5. **抖动**：无论有没有暗场都建议开，几帧一次，偏移几个到十几个像素。

### 常见误区

| 误区 | 实际 |
|---|---|
| 「暗场能降噪」 | 暗场去除的是固定图案；随机噪声只会因为减暗场而**略微增加**。降噪靠更长总曝光和制冷 |
| 「平场可以用后期去梯度代替」 | 去梯度是减法，只能拉平背景；暗角对星云本身的压暗是乘性的，减法修不了；灰尘圈也拟合不出来 |
| 「平场越亮越好」 | 过曝进入非线性区，除法会引入新的不均匀 |
| 「主暗场减了偏置，又在校准时再减一次偏置」 | 偏置被减两次。软件里要选清楚暗场是否已含偏置（`calibrate.py` 的处理见其文档字符串） |
| 「平场不用减平场暗场」 | 平场里的偏置会让归一化后的平场变「浅」，校准后暗角修不干净甚至反过来（过校正，边缘变亮） |
| 「单反用 Dark 就够了」 | 温度不匹配的暗场可能比不减还糟，不如用抖动 + 离群值剔除 + 坏点修复 |

### 本仓库的情况

本仓库的 M27 示例数据**没有任何校准帧**（见根目录 README 第 1 节），所以：

- `process/stack.py` 用 3×3 中值替换热像素（相当于 CosmeticCorrection）代替暗场
- 暗角和梯度用多项式背景模型在后期处理（`scripts/gradient_removal.py`，可选 `--divide` 按乘性处理）
- 有校准帧时用 `scripts/calibrate.py` 走完整流程
